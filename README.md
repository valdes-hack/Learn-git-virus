## 🎯 Double Objectif du Projet

1. **Cybersécurité & Virologie Informatique :**
   - Étude exhaustive des familles de logiciels malveillants (Virus, Vers, Trojans, Ransomwares, Rootkits, etc.).
   - Analyse technique approfondie de **Win32/Expiro** : structure PE, détournement de l'EntryPoint (OEP), polymorphisme, C2, désinfection et limites.
   - Simulateur visuel interactif inoffensif (inspection de structures d'exécutables PE Windows).
   - Quiz de validation et glossaire terminologique complet.

2. **Maîtrise Professionnelle de Git & GitHub :**
   - Registre d'audit en direct intégrant **plus de 65 commandes Git de base distinctes**.
   - Bouton d'accès permanent dans le **Footer** pour consulter la liste complète, les fiches didactiques et tester ses connaissances.
   - Système d'auto-évaluation avec cases à cocher persistantes (`localStorage`).
   - Respect d'un workflow professionnel multi-branches (`main`, `develop`, `feature/*`).

---

## 💻 Architecture Technique

- **Front-End :** HTML5 sémantique, CSS3 (variables, mode sombre/clair, Flexbox/Grid), JavaScript ES6+ modulaire natif.
- **Zéro dépendance :** Aucun framework (ni React, ni Vue, ni bundleur lourd), exécution locale instantanée.
- **Hébergement & Collaboration :** GitHub repository : `https://github.com/valdes-hack/Learn-git-virus`.

## 📋 Registre des Commandes Git

Le registre des commandes Git est accessible directement depuis le footer de l'application ou via l'ancre `#git-tracker`. Chaque commande fait l'objet d'une fiche technique :
- Commande de base distincte (règle stricte : 1 commande de base = 1 entrée unique)
- Catégorie
- Syntaxe exacte
- Utilité pratique dans le projet
- Date et contexte réel d'exécution
- Statut d'apprentissage interactif
