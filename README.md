## Double Objectif du Projet

1. **Cybersécurité & Virologie Informatique :**
   - Étude exhaustive des familles de logiciels malveillants (Virus, Vers, Trojans, Ransomwares, Rootkits, Spywares, Keyloggers, Bootkits, Botnets, Adwares).
   - Analyse technique approfondie de **Win32/Expiro** : structure PE, détournement de l'EntryPoint (OEP), polymorphisme, C2, désinfection et limites.
   - Simulateur visuel interactif inoffensif (inspection de structures d'exécutables PE Windows).
   - Quiz de validation et glossaire terminologique complet.
   - Iconographie professionnelle standardisée via Boxicons (zéro emoji).

2. **Maîtrise Professionnelle de Git & GitHub :**
   - Registre d'audit en direct intégrant **72 commandes Git de base distinctes**.
   - Accès discret sous forme de passage secret (icône terminal avec pulsation discrète) dans le **Footer**.
   - Console d'audit chronologique réelle affichant la date et l'heure exacte de chaque commande exécutée.
   - Système d'auto-évaluation avec cases à cocher persistantes (`localStorage`).
   - Respect d'un workflow multi-branches (`main`, `develop`, `feature/*`).

---

## Architecture Technique

- **Front-End :** HTML5 sémantique, CSS3 (variables, mode sombre/clair, Flexbox/Grid), JavaScript natif autonome compatible double-clic direct `file:///` et serveurs HTTP.
- **Iconographie :** Boxicons CDN.
- **Hébergement & Collaboration :** GitHub repository : `https://github.com/valdes-hack/Learn-git-virus`.

---

## Registre & Console Horodatée

Le registre des commandes Git est accessible directement via le passage secret discret du footer ou via l'ancre `#git-tracker`.
Il propose deux vues complémentaires :
1. **Grille d'Apprentissage & Auto-Évaluation :** Cartes interactives, recherche textuelle, filtres de catégories et statut, modales techniques.
2. **Console d'Audit Chronologique Réel :** Journal terminal listant les 72 commandes avec date, heure exacte, branche, invite de commande et journal de sortie.
